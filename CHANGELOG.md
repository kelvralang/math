# Changelog

## 0.2.0

- Set Mog 0.1.4 as the minimum supported runtime, the first release that embeds
  its configured package-compatibility version correctly.
- Add pinned CI/release automation with tag checks, 0.1.4/current-runtime tests,
  checksummed archives, and automated action updates.
- Convert the manual import fixture into a validated public source package.
- Add canonical package metadata, runtime compatibility, API contract, tests,
  changelog, and license file.
- Add numeric constants and helpers for absolute values, bounds, clamping,
  powers, roots, floor, ceiling, and rounding.
- Preserve all exports from the initial import-test release.
